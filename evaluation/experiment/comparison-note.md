# Q2 comparison: applicability preview (one-page note)

**Question and design.** Would a structured pre-model applicability preview help the existing recommender interpret nested prerequisites and unknowns? Baseline retained its reasonable evidence/missing-information prompt, canonical clinical fields, BM25 diagnostic-protocol/category ranking and final source guards/advice links. Improved added only a card-ID/status preview from that same limited checker before model selection. This is a within-RAG comparison, not RAG versus no retrieval. Both modes remain runnable in one Streamlit app.

**Controls.** After development, six unchanged fictional inputs and source-linked expected checklists were frozen at 22 October 2026 00:58:49 Asia/Dhaka, before comparison calls. Nineteen code/data/plan files were hashed. Twelve fresh calls used Groq Qwen 3.8 27B, temperature 0, reasoning none and maximum completion 900. Retrieval, patient input, system prompt, schema and postprocessing were identical within each pair; exact saved requests verify only the preview differed. Case order was paired with alternating first mode. No expected answers entered inference, no failed answer was replaced, and no development-policy replay was used.

**Result and cost.** Source-reviewed final outputs passed 23/24 checks in each mode; 5/6 cases passed all four. Key behaviour passed 5/6, citations 6/6, restrictions 6/6 and honest missing-information handling 6/6 in both; NA=0. There were zero matched fail-to-pass gains or pass-to-fail losses. Improved used 708 additional input tokens across six calls (35,905 versus 36,613), nine more completion tokens, and no additional calls. Mean elapsed time was 1.4882 s baseline versus 1.5371 s improved, excluding quota waits; this small difference is not a reliable latency effect. The prespecified success criterion was not met.

**Failure, explanation and next test.** C05 still omitted epidemiology clarification required by its frozen checklist. Improved added conditional chikungunya test options, a partial gain that did not satisfy the full check. Its retrieved secondary cards/question slots lacked exposure questions, which a status-only preview cannot recover. In C04, both raw model responses still chose unestablished admission; their shared final guard prevented display. Coarse status labels and strong common guards likely limited measurable gains. Model variability is a plausible alternative explanation for the changed C05 selection; one run per mode cannot resolve it. Generic template instructions also remain less personalized than the actual questions. Next test: repeated matched runs on independent onset/exposure and admission-trigger counterfactuals with blinded clinical review, separately testing evidence/question coverage. These self-authored development-familiar cases and assistant source review are not independent clinical validation or clinical accuracy estimates.
